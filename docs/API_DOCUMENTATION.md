# EduSphere CBSE — API Documentation (Reference)

Compact reference. For rationale behind these conventions, see the "API Architecture"
section of `docs/ARCHITECTURE.md`. Once Phase 2+ is implemented, this doc should link to
the live OpenAPI/Swagger UI (`/docs`) generated by FastAPI as the source of truth for exact
request/response schemas.

## Base URL & Versioning

All endpoints are namespaced under `/api/v1`.

## Standard Response Envelope

**Success:**

```json
{
  "success": true,
  "data": {},
  "meta": { "page": 1, "page_size": 20, "total": 0 }
}
```

`meta` is present only on list/paginated endpoints.

**Error:**

```json
{
  "success": false,
  "error": {
    "code": "COURSE_NOT_FOUND",
    "message": "Course not found"
  }
}
```

## Standard Error Codes / HTTP Status Mapping

| HTTP status | Meaning | Example `error.code` |
|---|---|---|
| 400 | Bad request / malformed input | `INVALID_REQUEST` |
| 401 | Not authenticated | `UNAUTHENTICATED` |
| 403 | Authenticated but not authorized | `PERMISSION_DENIED` |
| 404 | Resource not found | `COURSE_NOT_FOUND`, `TEST_NOT_FOUND`, ... |
| 409 | Conflict (duplicate, state conflict) | `EMAIL_ALREADY_REGISTERED` |
| 422 | Validation error | `VALIDATION_ERROR` |
| 429 | Rate limited | `RATE_LIMITED` |
| 500 | Unhandled server error | `INTERNAL_ERROR` |

## Pagination, Filtering, Sorting

- `?page=1&page_size=20` — offset pagination for admin/browse views.
- Cursor-based pagination for high-volume feeds (`notifications`, `audit_logs`) — exact
  param shape TBD at implementation time.
- `?filter[class_id]=...&filter[subject_id]=...` — module-specific filters.
- `?sort=-created_at` — `-` prefix for descending.

## Auth Endpoints

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/v1/auth/register` | Create account (student/parent/teacher signup) |
| POST | `/api/v1/auth/login` | Issue access + refresh token |
| POST | `/api/v1/auth/refresh` | Rotate access token using refresh token |
| POST | `/api/v1/auth/logout` | Revoke refresh token |
| POST | `/api/v1/auth/password-reset` | Request/complete password reset |

| Module | Base path | Representative endpoints |
|---|---|---|
| users | `/api/v1/users` | `GET /me`, `PATCH /me`, admin CRUD |

| courses | `/api/v1/courses` | list/get, `POST /courses/{id}/enroll` |

| materials | `/api/v1/materials` | list/filter, `GET /{id}/download` |
| tests | `/api/v1/tests` | list/get, `POST /{id}/start`, `POST /{id}/submit`, `GET /{id}/result` |
| live_classes | `/api/v1/live-classes` | list/get, `POST /{id}/join`, `GET /{id}/attendance` |
| qna | `/api/v1/qna` | `POST /questions`, `POST /questions/{id}/answers`, `POST /answers/{id}/upvote` |
| subscriptions | `/api/v1/subscriptions` | `GET /plans`, `POST /subscribe`, `POST /cancel` |
| payments | `/api/v1/payments` | `POST /create`, `POST /webhook` |
| notifications | `/api/v1/notifications` | `GET /`, `POST /{id}/read` |
| support | `/api/v1/support` | `POST /tickets`, `GET /tickets/{id}`, `POST /tickets/{id}/messages` |
| gamification | `/api/v1/achievements` | `GET /me`, `GET /leaderboard` |
| analytics | `/api/v1/analytics` | role-scoped dashboards (`/analytics/student`, `/analytics/teacher`, `/analytics/admin`) |
| ai | `/api/v1/ai` | `POST /ask`, `POST /generate-practice-questions` |

Full per-field request/response schemas will be defined module-by-module during
implementation and surfaced automatically via FastAPI's generated OpenAPI spec.
